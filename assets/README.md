# assets

| File | Where it appears |
|------|------------------|
| `mascot.png` | README header |
| `logo.png` | The navigation rail, bundled with the app |
| `app_icon.ico` | The executable, copied over the scaffold at build time |

`logo.png` and `app_icon.ico` are cut from `mascot.png`: the flat white field is
flood filled away from the corners, so the white inside the drawing — the eyes,
the fur highlights, the sparks off the dustpan — survives. Redraw them if the
mascot changes.
